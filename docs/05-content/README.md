# 05. CONTENT

## 1. Content Strategy
The content strategy focuses on strict academic precision aligned with Tribhuvan University Faculty of Education guidelines, coupled with engaging multimedia presentations. Content is designed to answer three questions for the learner:
1. *What TU exam questions does this lesson answer?*
2. *What is the theoretical and practical framework?*
3. *How do I synthesize this into an exam-ready answer?*

## 2. Content Requirements
- Every course must include:
  - Course Code & Title (e.g., `Eng. Ed. 416: Phonetics and Phonology`).
  - Target academic year (1st, 2nd, 3rd, or 4th Year).
  - Curriculum overview & unit-wise syllabus breakdown.
- Every lesson must include:
  - Video Lecture (YouTube ID link).
  - Markdown lesson notes explaining key definitions, phonetic symbols, or textual analyses.
  - Downloadable resources (PDF slide summaries, past paper questions).
  - Duration estimate (e.g., "24 mins").

## 9. Content Style Guide
- **Academic Names:** Capitalize linguistic terms and titles correctly (e.g., *International Phonetic Alphabet (IPA)*, *Minimal Pairs*, *Structural Linguistics*).
- **Phonetic Symbols:** Display IPA using Unicode standard (`/θ/`, `/ð/`, `/ʃ/`, `/ʒ/`, `/ŋ/`).
- **Nepali Translations:** Provided in parentheses for complex pedagogical concepts to assist students with English-as-a-Second-Language comprehension.
